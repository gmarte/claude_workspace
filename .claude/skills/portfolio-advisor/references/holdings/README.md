# Holdings Reference Cards

One file per ETF position. Each card covers:

- **Key facts** — issuer, expense ratio, benchmark, yield
- **What it holds** — sector/country weights, top holdings
- **NRA tax treatment** — withholding rates, net yield after tax for DR resident
- **IPS role** — target allocation, rebalancing bands, rationale
- **Annual review checklist** — what to verify each year
