# Orbit Weekly Content Skill

This skill automates the weekly social media content production pipeline for OrbitFamily. It performs trend research, drafts a script featuring the locked roster characters, generates 9:16 vertical Veo 3.1 prompts (no music, no text), and formats platform-specific captions.

## How to Trigger

Trigger this skill whenever you want to generate social media content for OrbitFamily. Example phrases:
- "Make this week's Orbit content"
- "I need the content brief for next week — focus on after-school meltdowns"
- "Orbit social content"
- "Weekly Orbit content brief"

## Output

The skill automatically does trend research via web search and produces a single markdown file in the current working directory:
`orbit-content-YYYY-MM-DD.md`
